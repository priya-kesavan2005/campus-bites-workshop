# Campus Bites

Campus Bites is a small, fictional food-ordering demo for a practical DevOps
workshop. It uses HTML, CSS and JavaScript in a single file.

## Try the app

1. Extract the starter ZIP.
2. Open `index.html` in a web browser.
3. Add menu items to the cart and check the item count and total.
4. Select **Clear cart** to start again.

You can also open the extracted folder in Visual Studio Code to explore the
files. No server, Node.js or additional packages are needed.

## Project files

- `index.html` - the menu, styling and cart logic.
- `README.md` - this introduction to the project.

## About the demo

This is not a real ordering service: it does not process orders or payments
or collect customer information. The cart is stored only while the page is
open and resets on refresh.

During the workshop, you will use this project to practise making changes
with Git and GitHub and running automated checks with GitHub Actions.
